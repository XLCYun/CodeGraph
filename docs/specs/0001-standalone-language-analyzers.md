# 直接提供 Code Graph 接口的语言分析器

关联 Narrant #205。此文记录 2026-10-21 由用户确认的修订范围；实现与验收进度另行记录。

## 用户已明确的方向

- 在现有 `XLCYun/CodeGraph` 同仓维护各语言分析器与公共契约。
- 每个发布的语言分析器本身具有可直接调用的公开入口，接收项目路径、文件选集与选项，
  并直接返回统一的 Code Graph 响应。
- 调用方无需先经过一个总 CLI，由它下载、启动分析器并转换结果；上一轮“总 CLI 管理
  分析器”的提案已被用户最新答复撤回。
- 各语言分析器是项目主要维护的产品，独立构建并打包发布，不再以 native helper 为产品名称。
- 完整图节点只来自选定文件。可以读取必要项目上下文来解析引用，选集外目标作为图外符号；
  不沿引用递归扩张结果图。
- Code Graph Difference 继续由 Narrant 计算；独立项目可用、实际发布和 Narrant 接入仍是总交付目标。

术语采用 [GLOSSARY](../../GLOSSARY.md) 中的 Language Analyzer（语言分析器）与
Analyzer Package（分析器包）。用户所称“语言知识包”在这里指可执行的分析器产品，
不是静态知识数据。源码目录采用 `analyzers/`。

## 已核对的实现差距

当前每个语言包复制一份相同 CLI；Narrant 负责下载、校验、安装和使用租约，并向 CLI
传入包目录。现有 CLI 一次只接受一个语言包，多语言分组、分析调用和合图仍在 Narrant。

各语言实现目前使用私有协议，要求调用方装配环境、平台声明和限制；公开输入验证、
目标 SDK 装配、完整构图与结果验证的一部分仍由 Rust 总 CLI/Host 承担。新的独立
分析器必须自行提供完整公开能力，不能仅替换旧命令的名字。公共实现可以复用，
但消费者不需要适配原私有协议或组装语言运行时命令。

Rust、Python、Go、C/C++ 当前已有原生入口；C/C++ 还带动态库与平台资源。
TS/JS、Java、C# 当前分别携带 Node、JVM、.NET 运行时。“可直接启动”与
“只有一个物理文件”是不同的分发要求。分析器运行时与被分析项目的目标 SDK 仍须区分。

当前公共和内部协议只有一个项目根，并要求显式文件列表；空列表返回空图。
各语言已有根内多项目或多配置能力，但没有通用的多个独立项目根输入，也没有
“省略文件列表就自动构图”的公开模式。多语言图合并不产生额外的跨语言 FFI 或调用解析能力。

此前通过的 CI 只验证旧实现，不能替代以下新方案的验收。

## 职责与分发

Narrant 等消费者负责固定版本下载、完整性校验、事务安装、使用租约、按语言调用和多语言
合图。CodeGraph 交付独立分析器、公共协议、发布清单与许可；分析器不安装其他分析器。
一个分析器包可以包含直接可调用的入口与随包依赖，不要求所有语言都是单个物理文件。
调用方只需启动对应分析器的入口，不需要拼接 Node、Java 或 dotnet 的执行命令。

每个入口具有固定语言身份，包内自行定位它所需的运行时和配置。不存在要求所有消费者先安装、
调用的总 CLI，也不再发布一份需另配语言包才能工作的通用 CLI。共享协议实现、图验证和
生命周期代码可以作为各分析器的私有实现复用；这不形成第二套消费者接口。

保留 Rust、TypeScript/JavaScript、Python、Java、Go、C#、C/C++，支持 macOS ARM64 与
Windows x64。分析器私有运行时与目标项目 SDK 继续分开；分析器发现已安装的目标 SDK，
不自动安装、更新目标工具链，不执行项目构建脚本。

## 分析接口

每次接收一个绝对项目根目录、可选的项目内相对文件列表和分析选项：

- 省略 `files`：按该语言项目配置发现源码，形成此次分析的选集。
- 显式 `files: []`：返回空图，不扫描整个项目。
- 显式非空列表：只为这些文件构图。其他源码可以用于解析，不因此加入完整图节点。
- 多个独立项目根：由调用方分别调用。共同项目根内的工作区和多模块配置遵循语言政策。

发现必须复用各语言的配置和只读加载规则，不能用无差别递归扩展名扫描代替项目源集。
发现失败、非法路径、缺少必需配置或目标 SDK、读取失败等均返回明确错误，不能当作成功空图。
文件选集与项目上下文均限制在既有允许读取范围内，路径逃逸、循环和大小限制继续有效。

使用本机 stdio JSON；stdout 只输出协议，stderr 输出有界诊断。每个进程处理一个请求，
ready 可核对语言、版本与协议，支持取消、超时和完整进程回收。选项保留测试代码开关与
Rust 三档依赖政策，输出保留既有六种类别、身份、自身内容、包含关系、引用与图外符号。

## 验收

- 独立 checkout 可构建、测试、打包各分析器，不依赖 Narrant 源码或安装。
- 七个分析器的公开入口均直接接受公共请求并返回有效 Code Graph；无需总 CLI 或私有配置参数。
- 七语言分别覆盖省略选集的配置发现、显式选集、显式空集，以及选集外引用不扩大完整节点范围。
- 各语言语义、来源、只读加载、SDK 政策、失败与取消回收在两个支持平台通过；保留已有验收。
- 包入口、身份、精确版本、归档边界、文件清单、哈希及随包依赖均经真实打包验收。
- 首个固定版本经审核、合并和双平台完整 CI 后实际发布，可下载并通过 Narrant 的真实消费验收。
- Narrant 继续完成两侧构图、差异与 Review；两仓必要 PR 合并并完成收尾后才关闭 #205。

不增加 HTTP、公开 Rust 库、持久索引、图缓存、新语言、新平台、跨语言 FFI 解析或
CodeGraph 图差异接口。本次不发布 Narrant 应用，不增加仓库、Issue 或用户聊天。
