# CodeGraph

CodeGraph is a standalone project for analyzing source code in multiple programming
languages and producing a common Code Graph through one CLI/JSON interface.

The initial implementation is being extracted from [Narrant](https://github.com/XLCYun/narrant).
Graph comparison remains in the consuming application. Development is tracked in
[Narrant issue #205](https://github.com/XLCYun/narrant/issues/205).

This repository is being initialized; no executable release is available yet.
